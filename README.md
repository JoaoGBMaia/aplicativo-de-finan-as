# Fluxo - Aplicativo de Finanças

Um aplicativo web simples para controle de finanças pessoais, feito com HTML,
CSS e JavaScript puro.

## Como usar

Abra o arquivo `index.html` no navegador.

## Funcionalidades

- Cadastro de receitas e despesas
- Resumo com saldo, receitas, despesas e taxa de economia
- Filtro por tipo de lançamento
- Análise de despesas por categoria
- Persistência automática no navegador usando `localStorage`

## Próximos passos possíveis

- Exportar dados para CSV
- Criar metas mensais
- Adicionar login e sincronização em nuvem
- Transformar em app React ou mobile
